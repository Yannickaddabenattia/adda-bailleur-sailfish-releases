# adda-bailleur-sailfish-releases

Édition Sailfish OS officielle d'ADDA Bailleur, pour les téléphones Jolla et les appareils sous Sailfish OS. Ce dépôt ne contient que les fichiers à télécharger, pas le code source.

- **Gratuite** et réservée à Sailfish OS. Sur un téléphone Android ordinaire, l'application ne s'ouvre pas.
- **Prérequis** : Sailfish OS avec **Android App Support** activé (Paramètres → Android App Support).
- **Installation** : téléchargez le fichier `.apk` depuis la page *Releases* directement sur le téléphone, puis ouvrez-le depuis l'application Fichiers (dossier Téléchargements).
- **Vérification** : le fichier `SHA256SUMS` permet de contrôler le téléchargement.

Site officiel : https://addabailleur.fr
